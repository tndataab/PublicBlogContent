## Setting Up Duende IdentityServer 7 From Scratch

This folder contains the demo code for setting up Duende IdentityServer 7.4.4 in an empty ASP.NET Core project. It shows the IdentityServer middleware, the sample UI pages, in-memory test users and configuration, and Serilog logging, so you can see which pieces make up a working OpenID Connect provider.
