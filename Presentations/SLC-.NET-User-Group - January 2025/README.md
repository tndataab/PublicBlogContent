# Demystifying authentication in ASP.NET Core

Presented at the <a href="https://www.meetup.com/the-slc-net-user-group/events/304962947/" target="_blank">Salt Lake City .NET User Group</a> 2025-01-09 online.

Video recording: <a href="https://youtu.be/2b29ixm1IvQ" target="_blank">Demystifying authentication in ASP.NET Core on YouTube</a>

Included in this folder is the presentation and the two applications used during the presentation.

## About the talk

In this talk, we explain how authentication works in ASP.NET Core 8, which can be complicated and have many different parts. We cover the main ideas, such as schemes, handlers, ClaimsPrincipal, claims, challenges, session cookies and more. It is a practical, in-depth look at how authentication actually works in ASP.NET Core 8.
