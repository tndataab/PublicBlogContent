## Backend-For-Frontend

This folder contains the demo code for the blog post about the Backend-For-Frontend pattern in ASP.NET Core 9.

## Blog posts

The code is used in the seven-part series on the BFF pattern in ASP.NET Core:

* [Implementing BFF Pattern in ASP.NET Core for SPAs](https://nestenius.se/net/implementing-bff-pattern-in-asp-net-core-for-spas/), part 1 of the series
* [BFF in ASP.NET Core #4 - Implementing a BFF from scratch](https://nestenius.se/net/bff-in-asp-net-core-4-implementing-a-bff-from-scratch/)
* [BFF in ASP.NET Core #5 - Automatic Token Renewal](https://nestenius.se/net/bff-in-asp-net-core-5-automatic-token-renewal/)
* [BFF in ASP.NET Core #7 - Introducing the Duende BFF Library](https://nestenius.se/net/bff-in-asp-net-core-7-introducing-the-duende-bff-library/)
* [The BFF Pattern: What It Is and Where to Start](https://nestenius.se/bff/), with all seven parts

## Learn more

* [Getting Started: Authentication and Authorization in .NET](https://dometrain.com/course/getting-started-authentication-and-authorization-in-dotnet/), my video course on Dometrain. It covers the cookie handler and cookie and ticket lifetimes, which is the session side of a BFF.
* [Getting Started: OpenID Connect](https://dometrain.com/course/getting-started-openid-connect/), my video course on Dometrain. It explains how OAuth 2 and OpenID Connect work at the protocol level, including the flows and tokens a BFF handles and why the Implicit Flow was deprecated for browser-based apps.
