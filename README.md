# Public content: ASP.NET Core authentication, IdentityServer and Azure demo code

This repository contains the code and resources that accompany my blog posts and presentations at [nestenius.se](https://nestenius.se/). The topics are authentication, identity and security in ASP.NET Core, plus some Azure and AI coding agent demos. Each folder has its own README that links to the related blog posts.

## Presentations and training
* **[Presentations](Presentations)**
  - Slides and source code for my public presentations.

## Source code
* **[AzureAppServices](AzureAppServices)**
  - PowerShell scripts for deploying a container to Azure App Services with a managed identity. See the [user-assigned](https://nestenius.se/azure/deploy-a-container-to-azure-app-services-using-azure-cli-and-user-assigned-managed-identity/) and [system-assigned](https://nestenius.se/azure/deploy-a-container-to-azure-app-services-using-a-system-assigned-identity/) blog posts.
* **[Backend-For-Frontend](Backend-For-Frontend)**
  - Code for the Backend-For-Frontend (BFF) in ASP.NET Core blog post series. See [The BFF Pattern: What It Is and Where to Start](https://nestenius.se/bff/).
* **[DataProtection-and-AzureKeyVault](DataProtection-and-AzureKeyVault)**
  - Code for the blog post [Persisting the ASP.NET Core Data Protection Key Ring in Azure Key Vault](https://nestenius.se/net/persisting-the-asp-net-core-data-protection-key-ring-in-azure-key-vault/).
* **[DataProtection-Debugger](DataProtection-Debugger)**
  - Code for the blog post [Introducing the Data Protection API Key Ring Debugger](https://nestenius.se/net/introducing-the-data-protection-api-key-ring-debugger/).
* **[DuendeIdentityServer7](DuendeIdentityServer7)**
  - Code for the blog post [Duende IdentityServer 7: A Complete Setup Guide for ASP.NET Core](https://nestenius.se/net/duende-identityserver-7-a-complete-setup-guide-for-asp-net-core/).
* **[ForwardedHeaders](ForwardedHeaders)**
  - Code for the blog posts on the Forwarded Headers Middleware in ASP.NET Core: [exploring](https://nestenius.se/net/exploring-the-forwarded-headers-middleware-in-asp-net-core/) and [configuring](https://nestenius.se/net/configuring-asp-net-core-forwarded-headers-middleware/) it.
* **[IdentityServer-in-Docker](IdentityServer-in-Docker)**
  - Code for the blog series where we Dockerize an IdentityServer solution for local development and debugging. See [IdentityServer: What It Is and Where to Start](https://nestenius.se/identityserver/).
* **[MyCodingAgent.NET](MyCodingAgent.NET)**
  - Code for the presentation How Does a Coding Agent Work.
